# Object Tracking DocC Tutorial

Apple Vision Pro와 visionOS에서 Object Tracking 공간 경험을 만드는 과정을 다루는 학습 자료입니다. Spatial Computing TechMap 1차 심사를 위한 공개 버전이며, 전체 개발 Repository가 아닌 DocC 공개 배포 전용 Repository입니다.

## 학습 범위

- Chapter 1: 추적 자산 만들기
- Chapter 2: Object Tracking 경험 구성하기
- Chapter 3: 가상 콘텐츠 확장하기
- Chapter 4: 실기기에서 검증하기

## 공개 문서

https://madebyrsh.github.io/2026TechMap_tutorial/tutorials/objecttrackingtutorials/

## 로컬 정적 빌드

Xcode 26.6이 설치된 macOS에서 Repository 루트를 기준으로 다음 명령을 실행합니다.

```sh
scripts/build-docc.sh
```

정적 사이트는 `.build/site`에 생성됩니다.
